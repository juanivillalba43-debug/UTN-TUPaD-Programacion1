# UTN · TUPaD: Programación 1

Trabajos prácticos de **Programación 1** de la *Tecnicatura Universitaria en Programación a Distancia* (Universidad Tecnológica Nacional, Argentina), hechos en **Python**.

**Autor:** Juan Ignacio Villalba

## Contenido

| Práctica | Tema | Archivo |
|---|---|---|
| [Práctica 1](Practica%201/) | Estructuras secuenciales, condicionales y repetitivas | `TP_repetitivas_condicionales_secuenciales.py` |
| [Práctica 2](Practica%202/) | Listas y listas anidadas (matrices) | `TP_listas.py` |

### Práctica 1: Estructuras de control
Cinco programas de consola que validan todas las entradas con `while` + `.isalpha()` / `.isdigit()`, sin usar `try/except`:
1. **Caja del Kiosco:** compra con descuentos, totales, ahorro y promedio.
2. **Acceso al Campus:** login con 3 intentos y menú con cambio de clave.
3. **Agenda de Turnos:** reservas y cancelaciones para lunes y martes, sin usar listas.
4. **Escape Room "La Bóveda":** juego de energía y tiempo con alarma y regla anti-spam.
5. **La Arena del Gladiador:** combate por turnos con golpe crítico, ráfagas y pociones.

### Práctica 2: Listas
Trece ejercicios: promedios, máximos y mínimos, ordenamiento con `sorted()`, eliminar duplicados, rotar una lista con slicing, matrices de temperaturas, notas y ventas, un Ta-Te-Ti en consola y búsqueda de elementos.

## Cómo ejecutarlo

Requiere Python 3.

```bash
python "Practica 1/TP_repetitivas_condicionales_secuenciales.py"
python "Practica 2/TP_listas.py"
```

Cada archivo corre todos sus ejercicios uno detrás del otro, por consola.
